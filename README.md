# Alado

Investigación sobre Alado, hecha a partir del portafolio https://unasaracastrillonch.wixsite.com/portafolio.

- [`docs/alado-portafolio.md`](docs/alado-portafolio.md): el documento principal. Tiene todo lo que el portafolio dice y muestra sobre Alado: la marca, los hitos, cómo planean una colección, cada colección de ropa y de hogar, y la descripción de las imágenes.
- [`docs/alado-imagenes.csv`](docs/alado-imagenes.csv): índice de las imágenes con su código, el archivo local, el nombre del archivo original y el enlace.
- [`docs/imagenes/`](docs/imagenes/): copia de todas las imágenes, con el código como nombre (`EQ-09.jpg`). En `alta-resolucion/` están las diapositivas y los artes con texto.
- [`docs/hojas-de-contacto/`](docs/hojas-de-contacto/): mosaicos de cada colección con los códigos de las imágenes.
- [`docs/textos-fuente/`](docs/textos-fuente/): el texto original de cada página.

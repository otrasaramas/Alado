# Alado

Casa de conocimiento de la marca **Alado**: cerebro de marca, estrategia y la investigación del portafolio. Todo lo de Alado vive aquí.

## Para el Codex de Andrés (empezar por aquí)
- [`docs/ALADO-CODEX.md`](docs/ALADO-CODEX.md): **documento condensado listo para pegar en Codex.** Todo Alado (marca, tono, público, visual, colecciones, ecosistema) en una página.

## Documentos de marca
- [`docs/cerebro-de-marca.md`](docs/cerebro-de-marca.md): la versión extensa del cerebro de marca (ADN, tono, personas, ecosistema, colecciones, método).
- [`docs/estrategia-redes.md`](docs/estrategia-redes.md): estrategia de Instagram (campaña Bride + sostenimiento general).
- [`docs/assets/`](docs/assets/): piezas de apoyo (guía de rodaje, sticker de ruta a la tienda).

## Investigación del portafolio (catálogo visual)
- [`docs/alado-portafolio.md`](docs/alado-portafolio.md): todo lo que el portafolio dice y muestra sobre Alado: la marca, los hitos, cómo planean una colección, cada colección de ropa y de hogar, y la descripción de las imágenes.
- [`docs/alado-imagenes.csv`](docs/alado-imagenes.csv): índice de las imágenes con su código, el archivo local, el nombre del archivo original y el enlace.
- [`docs/imagenes/`](docs/imagenes/): copia de todas las imágenes, con el código como nombre (`EQ-09.jpg`). En `alta-resolucion/` están las diapositivas y los artes con texto.
- [`docs/hojas-de-contacto/`](docs/hojas-de-contacto/): mosaicos de cada colección con los códigos de las imágenes.
- [`docs/textos-fuente/`](docs/textos-fuente/): el texto original de cada página.
